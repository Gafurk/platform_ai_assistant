01. Инструкция: Добавление объекта недвижимости

1.Цель инструкции 
Обеспечить правильные и понятные подсказки пользователю при добавлении объекта недвижимости 

Бот должен: 
- распознавать, когда пользователь хочет добавить объект; 
- объяснять, как работает процесс; 
- корректно реагировать на ошибки.

2.Когда активируется инструкция
Инструкция активируется, если пользователь спрашивает:
 - как добавить объект;
 - как добавить квартиру, дом, офис или земельный участок;
 - не могу найти улицу;
 - не могу добавить земельный участок;
 - как узнать кадастровый номер;
 - не получается добавить объект;
 - как добавить объект через адресный регистр;
 - как добавить объект через кадастровый номер;
 - возникла проблема при добавлении;
 - ошибка при поиске адреса.

3.	Сценарии и ответы
3.1 Пользователь находится на главной странице
Контекст страницы: Главная страница ЛК Потребителя.

Ответ бота:
Для добавления объекта недвижимости вы должны являться собственником данного объекта.
1. На Главной странице зайдите в раздел «Объекты недвижимости» и нажмите «Добавить».
2. Выберите способ добавления объекта:
- «Через адресный регистр» — подходит для квартир, домов, офисов;
- «Через кадастр» — рекомендуется, если объект является земельным участком.
3. Выберите тип объекта недвижимости из списка: квартира, дом, офис, земельный участок и т.д.





4. Заполните форму поиска:
- область / город республиканского значения;
- район / город областного значения;
- населённый пункт;
- улица;
- дом;
- квартира / помещение, если применимо.
5. Нажмите «Получить кадастровый номер» и дождитесь автоматического определения данных.
6. После получения кадастрового номера нажмите «Отправить запрос» для проверки собственника.
7. После успешной проверки нажмите «Обновить», чтобы отобразить актуальную информацию по объекту.
После этого объект появится в списке «Объекты недвижимости».

3.2 Пользователь добавляет объект через адресный регистр
Контекст страницы: Добавление объекта недвижимости через адресный регистр.

Ответ бота:
Вы находитесь на странице добавления недвижимости через адресный регистр.
1. Выберите вид недвижимости.
2. Укажите область / город республиканского значения, район / город областного значения, населённый пункт, улицу и номер дома, если требуется.
3. Нажмите «Получить кадастровый номер».

3.3 Пользователь не может найти улицу или номер дома
Контекст страницы: Добавление объекта недвижимости через адресный регистр.

Ответ бота:
Если вы не видите свою улицу или номер дома в списке, проверьте:
- правильно ли выбраны область / город республиканского значения;
- правильно ли выбраны район / город областного значения и населённый пункт;
- нет ли опечаток в названии улицы, например Ё/Е, А/Ә, дефисы или пробелы.

Если улица всё равно не отображается, возможно, она отсутствует в адресном регистре или указана под другим названием.

В этом случае вы можете:
- попробовать добавить объект через кадастр;
- обратиться в поддержку по номеру +7 775 990 15 36.





3.4 Пользователь добавляет объект через кадастровый номер
Контекст страницы: Добавление объекта недвижимости через кадастровый номер.

Ответ бота:
Вы находитесь на странице добавления объекта недвижимости через кадастровый номер.
Укажите кадастровый номер объекта в соответствующее поле. После ввода нажмите «Отправить запрос» — система выполнит проверку собственника и автоматически подтянет данные об объекте.
Когда данные загрузятся, нажмите «Обновить», чтобы отобразить актуальную информацию по объекту.

Если вы не уверены, где найти кадастровый номер, его можно посмотреть в:
- правоустанавливающих документах;
- кадастровой справке;
- госактах на земельный участок.
В случае затруднений вы можете обратиться в поддержку по номеру +7 775 990 15 36.

3.5 Некорректный кадастровый номер / статус запроса — ошибка
Контекст страницы: Добавление объекта недвижимости через кадастровый номер.

Ответ бота:
Указан некорректный кадастровый номер.
1. Убедитесь, что вы указали полный кадастровый номер объекта недвижимости:
- для квартиры — номер должен содержать данные до уровня квартиры;
- для дома или земельного участка — номер должен быть указан до номера дома или участка.

Правильный кадастровый номер можно посмотреть в документах:
- справка о зарегистрированных правах на недвижимость;
- кадастровая выписка;
- правоустанавливающие документы.

Получить эти документы можно также онлайн через портал eGov:
https://egov.kz

2. Убедитесь, что вы являетесь собственником объекта. Иначе система не позволит 
добавить его в личный кабинет.
В случае затруднений вы можете обратиться в поддержку по номеру +7 775 990 15 36.
