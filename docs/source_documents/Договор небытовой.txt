03. Инструкция: Договор небытовой

Цель инструкции
Помочь пользователю корректно заполнить заявление для заключения договора электроснабжения (небытовой, для юридических лиц и ИП).

Бот должен:
- распознавать, когда пользователь хочет заключить небытовой договор электроснабжения;
- объяснять пошагово, как заполнить форму;
- корректно реагировать на вопросы по каждому шагу.

Данная инструкция предназначена для юридических лиц и индивидуальных предпринимателей, использующих электрическую энергию в предпринимательской деятельности.
Если пользователь является физическим лицом и использует электрическую энергию исключительно для собственных бытовых нужд, ему необходимо выбрать услугу "Заявление об акцепте договора электроснабжения для бытовых потребителей" (см. инструкцию 02. Договор бытовой).

---

Шаг 1. "Данные заявителя"

На первом шаге необходимо заполнить данные заявителя и организации, а также указать сведения по объекту недвижимости. Система автоматически заполняет БИН, наименование организации, если данные доступны.

Пожалуйста:
1. Проверьте корректность БИН, наименования организации.
2. Заполните ФИО руководителя.
3. Укажите, подается ли заявление от имени руководителя. Если нет - заполните ФИО заявителя.
4. Укажите контактный телефон и электронный адрес (e-mail) для получения уведомлений.
5. Выберите право собственности.
6. Выберите объект недвижимости.
7. Загрузите правоустанавливающий документ на объект недвижимости (при необходимости).

После заполнения всех обязательных полей нажмите кнопку "Далее", чтобы перейти к следующему шагу.

---

Шаг 2. "Заявление об акцепте договора"

На втором шаге необходимо указать сведения по договору и объекту недвижимости.

Пожалуйста:
1. Выберите поставщика услуг - организацию, осуществляющую заключение договора.
2. Выберите, состоит ли объект в кондоминиуме (Многоквартирный жилой дом) - выберите из доступных вариантов: Да или Нет.
3. Укажите причину заявления - выберите из доступных вариантов: вновь вводимый объект недвижимости или смена владельца.
4. Укажите вид объекта недвижимости - например: встроенное помещение, пристроенное помещение, гостиница, кинотеатр и т.д.
5. Укажите количество проживающих по прописке.

После заполнения всех обязательных полей нажмите кнопку "Далее", чтобы перейти к следующему шагу.

---

Шаг 3. "Заявление об акцепте договора 2"

На данном шаге необходимо ознакомиться с согласиями, указать способ получения уведомлений и способ получения платежного документа (ЕПД, счет-квитанция).

Пожалуйста, ознакомьтесь и подтвердите следующие согласия:
1. Согласие на получение уведомлений о прекращении электроснабжения указанным ниже способом.
2. Согласие на передачу документов, предусмотренных п. 4 или 4-1 Правил пользования ЭЭ, в ЭСО для заключения договора электроснабжения.

Далее необходимо:
- Выбрать способ получения уведомления - выберите из доступных вариантов: Электронная почта, почтовый адрес, СМС или Мессенджер.
- Указать наименование энергоснабжающей организации - организация, осуществляющая поставку электрической энергии.

После заполнения всех обязательных полей нажмите кнопку "Далее", чтобы перейти к следующему шагу.

---

Шаг 4. "Документы, прилагаемые к заявлению"

На этом шаге необходимо загрузить документы, прилагаемые к заявлению, и подписать заявление.

Перечень документов для юридического лица:
- Справка о государственной регистрации юридического лица;
- Выписка из государственного электронного реестра должностей и уведомлений;
- Справка о зарегистрированных правах на недвижимое имущество или правоустанавливающий документ;
- Акт разграничения балансовой принадлежности электросетей и эксплуатационной ответственности сторон (при наличии);
- Акт допуска в эксплуатацию энергоустановки с самой системой подключения потребителя к электрическим сетям (при наличии);
- Технические условия с приложениями (если есть);
- Документ, подтверждающий полномочия лица, подписывающего договор (если подает не первый руководитель): доверенность, приказ о назначении на должность, протокол избрания или назначения.
- Балансовые реквизиты.

Вы можете:
- перетащить файл в соответствующее поле;
- либо нажать на область загрузки, чтобы выбрать файл с устройства.

Максимальный размер одного файла - до 10 МБ.
Допустимые форматы: PDF, JPEG, JPG.

После загрузки необходимых файлов нажмите "Подписать".

Для завершения подачи заявления выберите удобный способ подписания:

ЭЦП (электронная цифровая подпись):
Если у вас есть действующий сертификат ЭЦП, выберите вкладку "ЭЦП" и нажмите кнопку "Выбрать сертификат". После выбора сертификата подпишите заявление - система автоматически проверит корректность данных.

Подписание по SMS (доступно только для физлиц):
Если вы хотите подписать заявление без ЭЦП, выберите вкладку "По SMS". Введите номер телефона, дождитесь SMS-кода, введите код из SMS и подтвердите подачу заявления.

После успешного подписания заявление будет отправлено поставщику услуг. Информация о статусе появится во вкладке "Обращения".
